# Отчет по изменениям (Changelog & Release Report)

## Не выпущено

### Исправлено
- «🛠 Изменить расписание сотрудника» не сохраняла смену ни у одного менеджера (данные писались до установки состояния FSM).
- Незарегистрированный пользователь, нажавший «✏️ Запросить изменение расписания», ронял обработчик.
- Текст кнопок меню сохранялся как дата/время смены, если пользователь застрял на шаге ввода.
- Повторное назначение смены на ту же дату создавало дубль вместо замены.

### Безопасность
- Обработчики кнопок проверяют права нажавшего: назначение ролей — только Администратор; заявки и смены — только руководитель своего филиала.
- Нельзя снять последнего Администратора.
- Пользовательский текст экранируется перед вставкой в HTML-сообщения.
- Удалён вшитый Telegram ID суперадмина по умолчанию; без `BOT_TOKEN`/`FIRST_SUPERADMIN_ID` бот не запускается.

### Изменено
- Даты вводятся как `ДД.ММ`, время — `08:00 - 20:00` или `Выходной`; хранение дат — `ГГГГ-ММ-ДД` (миграция старой базы при запуске).
- SQL вынесен в `db.py`, разбор дат — в `shifts.py`; «Расписание филиала» одним запросом.
- Зависимости закреплены точными версиями; логи пишутся и в консоль.
- Удалены `bot_update_v1.1.0.patch` и `GEMINI.md`; добавлены `README.md` и тесты (`tests/`).

## Версия 1.1.0 — Обновление стабильности, UX и безопасности

**Дата выпуска:** 1 октября 2026 г.  
**Разработчик:** Antigravity AI Coding Agent  
**Файл патча:** `bot_update_v1.1.0.patch`

---

### 1. Цели обновления
1. Повысить безопасность работы с учетными данными и исключить случайную утечку конфиденциальной информации в репозиторий.
2. Устранить проблему «зависания» пользователей в FSM-состояниях при ошибках ввода или отказе от действия.
3. Расширить функциональность бота для удобного самообслуживания сотрудников (профиль, справка).
4. Подготовить проект к совместной разработке и публикации на GitHub.

---

### 2. Сводка изменений

#### 🛡 Безопасность и конфигурация:
- **Автоматическая загрузка `.env`**: Добавлена функция `load_env()` с fallback-парсером без обязательных сторонних библиотек (и поддержка `python-dotenv`). Теперь токены и ключи подтягиваются из файла `.env` автоматически.
- **Файл `.gitignore`**: Сформирован файл исключений для Git. В репозиторий больше не попадут база данных SQLite (`*.db`), виртуальное окружение (`.venv/`), локальные переменные (`.env`), кэш байт-кода (`__pycache__/`) и системные файлы (`.DS_Store`).
- **Обновление зависимостей**: В `requirements.txt` добавлена библиотека `python-dotenv>=1.0.0`.

#### ⚡️ Новая функциональность (Features):
- **Команда `/cancel` и сброс состояний**:
  - Реализован глобальный обработчик команды `/cancel` и текстового сообщения «❌ Отмена», активный в любом состоянии FSM.
  - При отмене пользователь немедленно возвращается в главное меню с восстановлением кнопок его роли.
- **Инлайн-кнопки «❌ Отмена»**:
  - Добавлена кнопка отмены в клавиатуру выбора филиалов (`get_branches_keyboard`).
  - Добавлена кнопка отмены в клавиатуру назначения ролей (`get_roles_keyboard`).
  - Добавлена кнопка отмены в меню выбора сотрудника при редактировании смены (`start_edit_schedule`).
- **Команда `/profile` и кнопка «👤 Мой профиль»**:
  - В главное меню всех ролей добавлена кнопка «👤 Мой профиль».
  - Позволяет пользователю в 1 клик узнать свой текущий Telegram ID, ФИО, филиал, должность и уровень доступа в боте.
- **Динамическая справка `/help`**:
  - Создана подробная справка по командам бота.
  - Содержимое справки адаптируется под роль запрашивающего (Работник видит свои команды, Менеджер — инструменты филиала, Администратор — команды управления системой).

#### 🎨 Улучшения пользовательского интерфейса (UI/UX):
- При каждом шаге ожидания ввода (ФИО, должность, дата смены, время, ID пользователя, текст рассылки) добавлена текстовая подсказка: `Для отмены введите /cancel`.
- Расписание оформлено с использованием удобного моноширинного шрифта для времени (`<code>08:00 - 20:00</code>`) и эмодзи-маркеров (`•`, `▫️`).

### 4. Инструкция по установке и тестированию патча

#### Применение патча вручную (на чистую версию):
```bash
git apply bot_update_v1.1.0.patch
# или утилитой patch:
patch -p0 < bot_update_v1.1.0.patch
```

#### Запуск и проверка:
```bash
# Активация виртуального окружения
source .venv/bin/activate

# Проверка синтаксиса
python3 -m py_compile bot.py

# Запуск бота
python3 bot.py
```

#### Чеклист тестирования функционала:
1. Запустить бота: `/start`
2. Отправить команду `/help` — проверить отображение команд в соответствии с ролью.
3. Отправить команду `/profile` или нажать кнопку «👤 Мой профиль» — проверить вывод карточки пользователя.
4. Начать процедуру «✏️ Запросить изменение расписания» и на этапе ввода даты ввести `/cancel` — убедиться, что бот вышел из режима ожидания и вернул клавиатуру меню.
5. Начать редактирование расписания сотрудника и нажать инлайн-кнопку «❌ Отмена» — убедиться, что сообщение сменилось на отмененное.
